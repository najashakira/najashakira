### 🚀 Featured Projects

#### 1. Banking Financial Performance Analysis (Published Research)
- **Publikasi Jurnal:** 📑 [Interest Margin, Operational Efficiency, Liquidity, and Bank Profitability: Does Firm Size Matter? (ICEMA Journal)](https://jurnal.amertainstitute.com/index.php/ICEMA/article/view/625)
- **Deskripsi:** Menganalisis pengaruh Net Interest Margin (NIM), Biaya Operasional Pendapatan Operasional (BOPO), dan Loan to Deposit Ratio (LDR) terhadap Return on Assets (ROA) dengan Firm Size sebagai variabel moderasi pada bank konvensional di Indonesia.
- **Output:** Terakreditasi SINTA 4 dan dipresentasikan pada International Conference on Economics, Management, and Accounting (ICEMA) 2026.
- **Tools:** Microsoft Excel, EViews, Stata.
